**“개발자는 배우고, 정리하고, 공유할 때 가장 크게 성장합니다💪”**

매주 온라인에서 모여 각자의 학습 내용을 발표하고 토론하며, 발표 역량과 기술적 깊이를 동시에 키워가는 스터디입니다. 개인의 자율적이고 자발적인 학습의 동기를 유지하면서도 다양한 시각의 지식을 접할 수 있어 혼자 공부할 때보다 더 넓고 깊은 성장을 경험할 수 있습니다!

## 운영 방식

- **일정**: 매주 목요일 21:00
- **발표**: 매주 2명이 각자 주제를 정해 발표합니다.
- **Q&A와 토론**: 발표가 끝나면 질문과 토론을 이어갑니다.
- **아티클 리뷰**: 함께 읽을 기술 아티클을 공유하고 리뷰합니다.

## 기록 방식

모든 발표 기록은 Markdown 파일로 작성해 Git 저장소에 커밋합니다.
새 파일을 push하면 사이트가 자동으로 다시 빌드되어 배포됩니다.
